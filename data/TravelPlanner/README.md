# TravelPlanner official dataset

Source: https://huggingface.co/datasets/osunlp/TravelPlanner

The files are stored without schema conversion:

- `train.csv`: 45 official training query-plan pairs.
- `validation.csv`: 180 official validation queries.
- `test.csv`: 1,000 official test queries.

The test release intentionally omits private fields used by the official
leaderboard. License: CC BY 4.0.
